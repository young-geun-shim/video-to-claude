# video-to-claude

영상 주소나 영상 파일을 주면 영상에서 말한 것과 화면에 나온 글자를 한 줄도 빼지 않고 글 파일로 옮기는 클로드 코드 스킬입니다. 글 파일만 받을 수도 있고, 요약 · 정리 · 가능한지 판단 · 설계 · 전수조사를 거쳐 영상 속 방법을 내 클로드 코드 환경(규칙 · 스킬 · 훅 · 설정 · 플러그인)에 들여오는 데까지 갈 수도 있습니다. 어디까지 갈지는 사용자가 정하고, 정한 곳에서 멈춥니다.

## 설치

클로드 설정 폴더(보통 `~/.claude`, `CLAUDE_CONFIG_DIR` 를 쓰면 그 폴더)의 `skills/` 아래로 받습니다.

```bash
git clone https://github.com/young-geun-shim/video-to-claude.git "${CLAUDE_CONFIG_DIR:-$HOME/.claude}/skills/video-to-claude"
```

새 창에서 스킬 목록에 `video-to-claude` 가 보이면 설치된 것입니다. 새 버전은 그 폴더에서 `git pull` 로 받습니다. 같은 이름의 폴더가 이미 있으면 `git clone` 이 멈추니, 그 폴더를 다른 곳으로 옮긴 뒤 다시 받으세요. git 을 쓰지 않으면 이 저장소 파일을 통째로 `skills/video-to-claude/` 에 넣어도 됩니다.

## 필요한 프로그램

- 늘 필요 = `yt-dlp` · `ffmpeg` · `node` · `python3`.
- 화면 글자를 읽을 때만 = `paddleocr` · `opencv-python`(파이썬 패키지, 불러올 때 이름은 `cv2`).
- 소리 받아쓰기(자막이 없는 영상)를 할 때만 = `faster-whisper`(파이썬 패키지).

자막 고르기의 사용자 언어는 `scripts/pick_langs.py` 의 `USER_LANG` 한 줄(기본 `"ko"`)이 정합니다. 한국어가 아닌 사용자는 그 줄을 자기 언어로 바꾸세요. 아래 개인 설정 파일은 스크립트가 아니라 클로드가 읽는 글이라 자막 고르기에는 걸리지 않습니다.

설치 명령은 환경마다 다르므로 `scripts/check_env.sh` 를 먼저 돌려 빠진 것과 고치는 방법을 안내받으세요.

```bash
bash "${CLAUDE_CONFIG_DIR:-$HOME/.claude}/skills/video-to-claude/scripts/check_env.sh"
```

## 부르는 말 예시

- 「이 영상 자막으로 뽑아내고 정리해줘 <주소>」
- 「유튜브를 스킬로 만들고 싶어 <주소>」
- 「이 영상 원문 가져와서 요약해줘」
- 「이 영상 우리 환경에 적용 가능한지 판단해줘」
- 「영상 세 개를 같이 보고 설계해 와」
- 「이 영상 내 클로드에 적용해줘」

요약을 먼저 해 드리고, 원하면 정리 · 판단 · 설계 · 적용까지 갈지와 환경 점검을 여쭙습니다. 「글 파일만」 「자막만」처럼 분명히 말하면 요약 없이 글 파일만 만듭니다.

## 폴더 짜임

- `SKILL.md` = 늘 읽히는 첫 파일. 길 고르기 표와 0단계.
- `references/` = 길마다 · 단계마다의 긴 규칙. 필요한 파일만 읽힙니다.
- `scripts/` = 받기 · 자막 옮기기 · 합치기 · 화면 글자 인식 · 소리 받아쓰기 · 환경 점검.

## 개인 설정 파일 (선택)

클로드 설정 폴더(보통 `~/.claude`, `CLAUDE_CONFIG_DIR` 를 쓰면 그 폴더) 안에 `video-to-claude.local.md` 를 두면 이 스킬이 맨 먼저 읽고, 그 안의 규칙을 스킬 글보다 앞에 둡니다. 작업 폴더를 어디에 둘지, 어떤 언어로 쓸지, 쓰지 말 낱말, 써 보고 싶은 다른 모델이나 도구 같은 개인 규칙을 거기에 적으세요. 스킬 폴더 밖이라 스킬을 새 버전으로 바꿔 끼워도 지워지지 않습니다. 없으면 건너뜁니다.

설정 폴더는 보통 작업 폴더 밖이라 클로드 코드가 읽기 허락을 물을 수 있습니다. 허락하지 않으면 개인 규칙이 적용되지 않습니다. 매번 묻지 않게 하려면 클로드 설정 파일(`~/.claude/settings.json`)의 `permissions.allow` 에 다음 한 줄을 넣으세요.

```json
"Read(//home/<사용자 이름>/.claude/video-to-claude.local.md)"
```

경로는 맨 앞에 `/` 를 하나 더 붙인 절대 경로로 적습니다(`~` 로 적은 규칙은 시험에서 통하지 않았습니다). 허락 규칙은 클로드가 여는 경로 글자와 똑같아야 통합니다. 그래서 `~/.claude` 가 다른 폴더로 이어지는 바로가기(심볼릭 링크)라면 바로가기 경로와 실제 경로(`readlink -f ~/.claude` 로 확인) 두 줄을 모두 넣으세요.

`claude -p` 처럼 묻지 않고 도는 실행에서는 허락 질문이 뜨지 않아 그대로 막힙니다. 그때도 위 한 줄이 있어야 읽힙니다.
