# 길 고르기 — 일곱 길마다 어떤 단계를 어떤 순서로 하고 무엇을 남기나

공통 = 모든 길은 SKILL.md 의 0단계(지시 읽기 → 전에 받은 영상 찾기 → 받기 → 요약 → 어디까지 갈지 여쭙기)로 시작한다. 지시가 길을 이미 정했으면 여쭙지 않는다. 길이 바뀌면(예 요약만 하려다 적용까지 가기로 함) 이어받기 표로 지금 폴더를 이어 쓰고, 이미 한 단계는 다시 하지 않는다.

## 1. 글 파일만

- 단계 = 0 → 1.
- 순서 = 받기 → `subs_to_md.py` 검산 → (화면 글자가 필요하면) 화면 글자 인식과 놓침 검산 → `merge.py`.
- 남기는 것 = `자막_전문.md` · `영상_전체텍스트{접미}.md`(원본 확인용) · `읽기용{접미}.md`(읽는 언어 한 벌 + 화면 글자) · 자막이 없어 소리를 받아썼으면 그 표시.
- 끝 = 파일 경로와 요지만 알리고 멈춘다.

## 2. 요약 / 정리

- 단계 = 0 → 1 → 2. 「요약」은 0단계 4번의 한 화면 요약에서 끝나고, 「정리」는 2단계까지 간다.
- 순서 = 글로 옮기기 → `발표자방법.md` → `항목표.md` → 항목표 태클 검토(있으면) → 쉬운 설명 화면(있으면 그 스킬로, 없으면 글) → 되살릴 것이 있는지 한 번 여쭙기.
- 남기는 것 = 1번 길의 파일 + `발표자방법.md` + `항목표{접미}.md`.
- 끝 = 가져올 후보와 버릴 후보를 보여 드리고 멈춘다. 가져오는 일은 하지 않는다.

## 3. 가능한지 판단

- 단계 = 0 → 1 → 2 → 3 가운데 「가져올 후보마다 가능한가」만. 4단계 넣을 곳은 정하지 않는다.
- 순서 = 2단계 항목표에서 「이미 있나」 칸을 빈틈없이 채운다 → 후보마다 가능 / 부분 가능(없는 것) / 불가능을 근거(파일:줄 · 원문 시각)와 함께 판정한다 → 판단 결과를 사용자의 문제(0단계 첫째)와 견준다.
- 남기는 것 = 2번 길의 파일 + `판단_YYYYMMDD.md`(번호 · 후보 · 판정 · 근거 · 막는 것 · 원문 시각).
- 끝 = 판정표를 알리고 멈춘다. 설계나 적용으로 가려면 길을 바꿔 4번이나 7번으로 이어간다.

## 4. 설계해 오기

- 단계 = 0 → 1 → 2 → 3 → 4, 그리고 5단계의 설계 검토 1번만(초안은 만들지 않는다). 그 절차는 `5_7_검토_시험_설치.md` 5번 1항에 있다.
- 순서 = 항목표 → 결정(`3_결정.md`) → 넣을 곳(`4_넣을곳.md`) → 설계를 원문과 대조하는 검토.
- 남기는 것 = 2번 길의 파일 + `인터뷰_중간.md` · `결정_YYYYMMDD.md` · `넣을곳_YYYYMMDD.md`.
- 끝 = 설계를 승인받고 멈춘다. 실제 자리(규칙 · 스킬 · 훅 · 설정)는 건드리지 않는다.

## 5. 전수조사

- 단계 = 0 → 1 → 2, 대신 빈틈을 허용하지 않는다.
- 순서 = 화면 글자 인식을 필수로 하고 놓침 검산 0 을 통과한다 → `발표자방법.md` 의 시각 구간표에 빈 구간 0 → 항목표에 발표자가 권한 걸음을 하나도 빼지 않고 올린다(버릴 것도 이유와 함께) → 하지 말라고 한 것을 따로 모은다.
- 부분만 읽는 길이면 나머지 구간을 훑는 일(`2_정리_항목표.md` 4번)을 반드시 한다.
- 남기는 것 = 2번 길의 파일 + 놓침 검산 결과(`분석/` 아래) + 구간표 빈 곳 0 이라는 확인 한 줄.
- 끝 = 못 읽은 구간이나 남는 위험(화면 영역 확대 · 이동 순간)을 숨기지 않고 적고 멈춘다.

## 6. 영상 여러 개

- 단계 = 영상마다 0 → 1 → 2, 그다음 한 번에 묶어 3(필요하면 4).
- 순서 = 영상마다 작업 폴더를 따로 만든다(한 폴더에 영상 하나) → 영상마다 받기 · 글로 옮기기 · 요약. 여러 영상의 화면 글자 인식을 동시에 돌리면 CPU 를 나눠 쓰니 `--jobs` 는 (CPU 수 ÷ 6)을 영상 수로 나눈 값으로 하고, 1보다 작으면 1로 한다 → 영상마다 `발표자방법.md` → 윗 폴더에 `여럿_비교표.md`(영상 · 같은 걸음 · 다른 걸음 · 서로 부딪히는 말 · 원문 시각)를 만든다 → 결정은 영상별로 나누지 않고 한 번에 묶어 여쭙는다(질문마다 어느 영상 말인지 적는다).
- 남기는 것 = 영상별 폴더 안 파일 + 윗 폴더의 `여럿_비교표.md` · 결정 문서.
- 끝 = 영상별 요약과 비교표를 알린다. 영상이 많아 한 창에 다 못 읽으면 영상별로 이어받기 파일을 남긴다.

## 7. 내 클로드에 적용

- 단계 = 0 → 7 전부.
- 순서 = 글로 옮기기 → 항목표 → 결정 → 넣을 곳 → 검토 + 초안 → 시험 → 서명 → 설치 → 새 창 확인 → 「앞으로 이렇게 쓰세요」 한 장(`5_7_검토_시험_설치.md`).
- 남기는 것 = 글 파일 · 항목표 · 결정 · 검토 결과 · 초안 · 시험 · 백업 · `이어받기*.md` · 앞으로 쓰는 법 한 장.
- 끝 = 설치 뒤 새 창에서 같은 시험이 통과한 것을 확인하고, 이미 켜진 창에는 언제부터 걸리는지 알린다.
