# 3단계 — 결정 (여쭙는 법)

1. 가져올 후보마다 목적에 맞춰 내가 정한다. **사용자에게 여쭙는 것은 항목표의 「부딪힘」과 사용자가 정한 규칙 · 권한과 부딪히는 항목뿐**이다. 나머지는 정한 것과 근거를 결정 문서 초안에 모아 한 번에 보여 드린다.
2. 여쭐 때는 하나씩, 추천 답 하나와 함께 묻는다. 한 번에 하나 묻는 인터뷰 스킬(예 `/grill-me`)이 있으면 그것으로, 없으면 이 글대로 한다.
3. **질문마다 첫 줄에 「왜 묻나」 + 「지금까지 정한 것」을 적는다.** 예 = 「왜 묻나 = 영상이 말한 방법이 지금 쓰는 규칙과 부딪혀서입니다. 지금까지 정한 것 = ①… ②…」. 그다음에 원문 시각 · 원문이 한 말 · 내 환경과 같은지 다른지 · 다르면 왜를 붙인다. 정한 것이 아직 없으면 「아직 정한 것 없음」이라고 쓴다. 영상이 말하는 사실은 사실이면 이유를 되묻고, 하지 말라고 한 것은 `발표자방법.md` 5번 칸과 맞댄 뒤 원문이 권한 행동으로 여쭙는다.
4. 낯선 개념이 든 질문은 처음부터 쉬운 설명 화면(`/eli5` 같은 스킬이 있으면)의 결정 장면으로 여쭙는다. 순서 = 맥락 → 개념 → 영상의 방법 → 내 환경 → 같은 예로 견주기 → 결정. 스킬이 없으면 같은 순서로 짧게 글로 쓴다. 글 질문은 이미 아는 낱말로만 된 짧은 것에만 쓴다. 설명 화면의 그림이 대본과 맞는지는 `2_정리_항목표.md` 4번처럼 화면을 찍어 확인한다.
5. 질문 하나를 마칠 때마다 `인터뷰_중간.md` 에 한 줄 적는다(번호 · 여쭌 것 · 정하신 것 · 원문 시각).
6. `결정_YYYYMMDD.md` = 정한 것(번호 · 무엇 · 왜(원문 시각) · 버린 다른 길) / 하지 않기로 한 것(ⓐⓑⓒ) / 아직 안 정한 것. 보여 드리고 승인받은 뒤 확정한다.
7. 「이해 못했어」면 멈추고 더 쉽게 다시 설명한다. 되묻힌 낱말은 다음 설명부터 쓰지 않는다.
8. 같은 영상인지 견줄 수 없을 때나 놓침 검산이 실패했을 때처럼 「그대로 진행하면 다른 글이 섞이거나 빠질 수 있는」 경우에는 멋대로 진행하지 않고 멈춰서 여쭙는다.
