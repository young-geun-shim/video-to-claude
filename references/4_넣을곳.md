# 4단계 — 넣을 곳

가져올 항목마다 넣을 곳 하나와 이유를 정해 `넣을곳_YYYYMMDD.md`(번호 · 무엇을 · 어디에 · 왜 · 원문 시각)에 적고 승인받는다. 한 흐름의 걸음은 한 자리에 모으거나, 흩어지면 순서를 적는다. 발표자의 걸음이 일어나는 순간과 같은 순간에 걸리는 자리를 먼저 고른다.

| 넣을 곳 | 이럴 때 |
|---|---|
| 스킬 `<설정 폴더>/skills/<이름>/SKILL.md` | 특정 일을 할 때만 필요한 긴 절차 |
| 플러그인 | 스킬 · 훅 · 스크립트를 한 묶음으로 두고 판본을 관리할 때 |
| 규칙 파일 `<설정 폴더>/CLAUDE.md` (프로젝트면 그 폴더의 `CLAUDE.md`) | 모든 창에서 매번 지켜야 하는 짧은 규칙 |
| 훅 (`settings.json` 의 hooks 나 플러그인의 `hooks.json`) | 내가 잊어도 기계가 반드시 막거나 붙여야 하는 것 |
| `settings.json` | 허용 · 금지 목록, 환경 변수 |
| 기억(메모리) | 한 번 알아 두면 되는 사실 |
| 서브에이전트 정의 `<설정 폴더>/agents/` | 특정 역할로 일을 따로 시킬 때 |
| 적용 안 함 | 글로만 남김 |

개인 환경에만 있는 자리(검사 관문 스크립트, 서브에이전트 공통 규칙 파일, 만들기 · 검토 · 고치기 흐름 등)는 개인 설정 파일(`video-to-claude.local.md`)이 이 표에 더한다.
